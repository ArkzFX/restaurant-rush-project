# Restaurant Rush: sample material for the group to review

This repository is a **sample for discussion**, not our final submission. It holds a worked example of the
SC2002 Restaurant Rush project in basic Java, so the group can read it, agree who does what, and decide how
to implement our own version.

| Folder | What it is |
|---|---|
| `stage-1/` | Stage 1: basic operation (Regular customers, Waiter, Chef, Cashier). Includes the Stage 1 class diagram. |
| `stage-2/` | Stage 2: adds VIP and Critic customers. README has the Stage 1 to 2 change table. Class diagrams for Stages 1 and 2. |
| `stage-3/` | Stage 3: adds Host, combo meals and Happy Hour. README has the Stage 2 to 3 change table. All three class diagrams and the sequence diagram. |
| `team-guides/` | Per-stage guides: who owns which files, what to ask an AI, what is safe to change, and reflection questions. |
| `video-script.md` | Draft outline for the 15-minute video, split across five presenters. |

Each stage folder builds and runs on its own (JDK 17 or newer). See the README inside each one.
`stage-3/test-runs/run-all.sh` replays every scripted run and the rule checks.

Everything we submit must be our own work: each member writes, understands and commits their own files,
keeps their own full AI chat history, and writes their own reflection.
